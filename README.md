This is a [Next.js](https://nextjs.org) project configured to build as a static site.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Static build

Create a production static export in the `out` directory:

```bash
npm run build
```

Deploy the contents of `out` to any static hosting provider. Runtime API routes and
server-side rendering are not available in the static export.

You can start editing the page by modifying `src/pages/index.tsx`. The page
auto-updates as you edit it.
